# Проверка карточки 1084: геолокация после отказа в системном окне

Мини-приложение для @latex1testbot. Показывает, что Telegram думает о доступе
бота к геолокации, и позволяет увидеть расхождение с тем, что ответила система.

## Что проверяем

По репорту в `BotLocation` результат системного запроса вычисляется и
игнорируется: `this.granted = true` вместо `this.granted = someGranted`.
Значит после нажатия «Запретить» в окне Android разрешение всё равно
сохраняется как выданное. Пока у самого Telegram нет прав на геолокацию, это
не видно; как только их выдадут для чего угодно другого — бот начинает
получать координаты без повторного вопроса.

Приложение показывает четыре флага моста: `isInited`, `isLocationAvailable`,
`isAccessRequested`, `isAccessGranted`. Ключевой — последний.

## Куда положить

Файл статический, нужен HTTPS — Telegram открывает мини-приложения только по
нему. Любой статический хостинг подойдёт, например GitHub Pages: положить
`index.html` в репозиторий, включить Pages, взять полученный адрес.

Локальный сервер TSO (`127.0.0.1:8768`) для этого не годится: он без HTTPS и
недоступен снаружи.

## Настройка бота

У @BotFather:

```
/newapp        -> выбрать @latex1testbot -> указать адрес страницы
```

или, если хватит кнопки меню:

```
/setmenubutton -> выбрать @latex1testbot -> указать адрес и подпись
```

Проверять на **Android**: дефект в андроидном клиенте.

## Порядок проверки

Часть 1 — отказ:

1. Убедиться, что у самого Telegram **нет** доступа к геолокации:
   Настройки Android → Приложения → Telegram → Разрешения → Местоположение →
   «Запретить».
2. Открыть мини-приложение бота, нажать «Запросить геолокацию».
3. В окне Telegram согласиться.
4. В системном окне Android нажать **«Запретить»**.
5. Нажать «Обновить флаги» и посмотреть на `isAccessGranted`.

Если он `true` — Telegram сохранил отказ как согласие. Приложение скажет об
этом прямым текстом.

Часть 2 — тихое включение:

6. Выдать Telegram доступ к местоположению в настройках Android (как будто для
   чего-то другого).
7. Полностью закрыть Telegram и открыть заново.
8. Открыть мини-приложение и нажать «Запросить геолокацию».

Если координаты придут **без повторного вопроса про бота** — воспроизведено.

Кнопка «Скопировать журнал» отдаёт все события с отметками времени: удобно
приложить к карточке вместе со скриншотами системных окон.

## Чего эта проверка не показывает

Только состояние на стороне клиента. Ни обхода системного разрешения Android,
ни слежки в фоне здесь нет, и автор репорта этого и не заявлял.
